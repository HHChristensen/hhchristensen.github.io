Privatliv og dataadgang

Ovnrapport GitHub bruges af kontoejeren til rapportberegning på egne udvalgte Google Drive-filer.

Adgang og formål

Appen anmoder om tilladelse til at se og administrere filer i den godkendte Google Drive-konto. Denne tilladelse er bredere end de mapper, rapportværktøjet bruger. Værktøjets opskrift afgrænser læsning til udpegede inputfiler og mapper og skrivning til den udpegede rapportmappe. Inputfiler og procesindstillinger ændres ikke af rapportværktøjet.

Der læses filoplysninger og filindhold til kontrol og beregning. Kontoens e-mailadresse læses for at kontrollere, at den godkendte driftskonto bruges. Der anmodes ikke om Gmail-adgang.

Behandling og opbevaring

Data hentes fra Google Drive og behandles midlertidigt i GitHub Actions. Google og GitHub indgår dermed som tekniske tjenester i behandlingen. Rapporter og driftsstatus gemmes i Google Drive. Adgangsoplysninger opbevares som GitHub Secrets.

Inputdata og rapporter lægges ikke i kodelageret, Actions-artefakter eller denne offentlige hjemmeside. De midlertidige arbejdskopier bruges under den enkelte GitHub-kørsel. Kontoejeren styrer opbevaring og sletning af filer i Google Drive. Oplysningerne bruges til rapportarbejdet og sælges ikke eller anvendes til reklame.

Kontoejerens kontrol

Kontoejeren kan tilbagekalde appens adgang i Google-kontoens sikkerhedsindstillinger og fjerne den gemte adgang i GitHub. Tilbagekaldelse sletter ikke allerede gemte input eller rapporter i Google Drive; disse administreres særskilt af kontoejeren.
